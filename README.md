# Расписание уроков

Мобильное приложение для управления школьным расписанием уроков с поддержкой виджетов и отображения на экране блокировки.

## Возможности

- **Управление расписанием**: Добавление, редактирование и удаление уроков
- **Недельное расписание**: Просмотр расписания по дням недели
- **Детализация уроков**: Указание предмета, времени, кабинета и преподавателя
- **Цветовая маркировка**: Назначение цветов для разных предметов
- **Виджет главного экрана**: Отображение текущих уроков на главном экране устройства
- **Уведомления**: Показ расписания в уведомлениях и на экране блокировки
- **Локальное хранилище**: Все данные сохраняются на устройстве
- **Темная тема**: Поддержка светлой и темной темы оформления

## Технологии

- **Flutter**: Кроссплатформенный фреймворк для разработки мобильных приложений
- **Provider**: Управление состоянием приложения
- **SharedPreferences**: Локальное хранение данных
- **home_widget**: Виджеты для главного экрана Android
- **flutter_local_notifications**: Локальные уведомления

## Установка и запуск

### Требования

- Flutter SDK (версия 3.0.0 или выше)
- Android SDK (для Android) или Xcode (для iOS)
- Dart SDK

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd school_schedule
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите генерацию кода (опционально):
```bash
flutter pub run build_runner build
```

4. Подключите устройство или запустите эмулятор

5. Запустите приложение:
```bash
flutter run
```

## Использование

### Добавление урока

1. Откройте приложение
2. Выберите день недели в верхней панели
3. Нажмите на кнопку "+" внизу экрана
4. Заполните информацию об уроке:
   - Предмет (обязательно)
   - Время начала и окончания (обязательно)
   - Кабинет (опционально)
   - Преподаватель (опционально)
   - Выберите цвет для урока
5. Нажмите на галочку в верхнем правом углу для сохранения

### Редактирование урока

1. Нажмите на карточку урока
2. Измените нужные поля
3. Нажмите на галочку для сохранения

### Удаление урока

1. Нажмите на иконку корзины на карточке урока
2. Подтвердите удаление

### Виджет главного экрана

После добавления уроков, виджет автоматически обновится и покажет расписание на текущий день.

Для добавления виджета на главный экран (Android):
1. Длинное нажатие на главном экране
2. Выберите "Виджеты"
3. Найдите "Расписание уроков"
4. Перетащите виджет на главный экран

### Уведомления на экране блокировки

1. Откройте меню в правом верхнем углу (три точки)
2. Выберите "Показать на экране блокировки" для одноразового уведомления
3. Или выберите "Постоянное уведомление" для создания постоянного уведомления с расписанием

Постоянное уведомление будет отображаться в шторке уведомлений и на экране блокировки.

## Особенности реализации

### Хранение данных

Приложение использует `SharedPreferences` для хранения расписания в формате JSON. Все данные сохраняются локально на устройстве и не требуют интернет-соединения.

### Виджеты

Виджеты для главного экрана реализованы с использованием пакета `home_widget`. Они автоматически обновляются при изменении расписания.

### Уведомления

Уведомления реализованы с использованием `flutter_local_notifications` и могут отображаться:
- Как обычные уведомления
- На экране блокировки
- Как постоянные уведомления

### Темизация

Приложение поддерживает автоматическое переключение между светлой и темной темой в зависимости от системных настроек.
