# Расписание уроков - Инструкция по использованию

## 📱 Описание приложения

Мобильное приложение для управления расписанием уроков с поддержкой 6-дневной учебной недели.

### Основные возможности:

- ✅ Добавление, редактирование и удаление уроков
- ✅ Расписание на всю неделю (Пн-Вс)
- ✅ Указание времени, кабинета и учителя
- ✅ Цветовая маркировка уроков
- ✅ **Уведомления на экране блокировки** с текущим расписанием
- ✅ **Android виджет** для домашнего экрана
- ✅ Светлая и темная тема (автоматически по системе)
- ✅ Локальное хранилище данных

## 📖 Как пользоваться приложением

### Добавление уроков:

1. Откройте приложение
2. Выберите день недели (вкладки вверху: Пн, Вт, Ср...)
3. Нажмите кнопку **"+"** внизу справа
4. Заполните:
   - **Предмет** (с автодополнением)
   - **Время начала и окончания** (выбор через диалог)
   - **Кабинет** (необязательно)
   - **Учитель** (необязательно)
   - **Цвет** для визуального отличия
5. Нажмите **галочку** ✓ вверху справа

### Редактирование урока:

1. Нажмите на карточку урока
2. Измените нужные поля
3. Сохраните изменения

### Удаление урока:

1. Нажмите на карточку урока
2. Нажмите кнопку **корзины** 🗑️

## 🔔 Уведомления на экране блокировки

### Способ 1: Временное уведомление

1. Откройте меню (три точки вверху справа)
2. Выберите **"Показать на экране блокировки"**
3. Разрешите уведомления (при первом запуске)
4. **Уведомление с ближайшим уроком** появится на экране блокировки

### Способ 2: Постоянное уведомление

1. Откройте меню (три точки вверху справа)
2. Выберите **"Постоянное уведомление"**
3. Уведомление будет **постоянно висеть** в панели уведомлений
4. Чтобы убрать - нажмите "Отменить" в snackbar или свайпните уведомление

### Важно для Android 13+:

При первом запуске Android может запросить разрешение на уведомления. Обязательно разрешите!

## 📲 Android виджет

### Как добавить виджет на домашний экран:

1. **Долгое нажатие** на пустое место домашнего экрана
2. Выберите **"Виджеты"** или **"Widgets"**
3. Найдите **"Расписание уроков"**
4. **Перетащите** виджет на домашний экран
5. Виджет автоматически покажет **сегодняшнее расписание** (до 3 уроков)

### Обновление виджета:

Виджет **автоматически обновляется** при изменении расписания в приложении.

### Примечание:

- Виджет показывает **только сегодняшние** уроки
- Отображаются **первые 3 урока** с временем и кабинетом
- Обновляется каждые **30 минут** или при изменении расписания

## ⚙️ Дополнительные возможности

### Очистка всего расписания:

1. Меню (три точки) → **"Очистить расписание"**
2. Подтвердите действие

### Автоматическое определение дня:

- Приложение автоматически открывается на **текущем дне недели**
- Вкладки позволяют быстро переключаться между днями

### Цветовая маркировка:

Используйте разные цвета для:
- Разных предметов
- Сложности предмета
- Типа урока (теория/практика)

## 🎨 Темы оформления

Приложение поддерживает светлую и темную темы:
- **Автоматически** следует системной теме Android
- Изменяется в настройках системы: **Настройки → Экран → Темная тема**

## 🐛 Решение проблем

### Уведомления не появляются:

1. **Настройки Android → Приложения → Расписание уроков → Уведомления**
2. Убедитесь что уведомления **разрешены**
3. Проверьте что канал "Расписание" **включен**

### Виджет не обновляется:

1. Удалите виджет с домашнего экрана
2. Откройте приложение и измените расписание
3. Добавьте виджет заново

### Приложение не запускается:

```powershell
# Переустановите зависимости
flutter clean
flutter pub get
flutter run
```

## 🔧 Технические детали

### Используемые библиотеки:

- **flutter** - Основной фреймворк
- **provider** - Управление состоянием
- **shared_preferences** - Локальное хранилище
- **flutter_local_notifications** - Уведомления
- **home_widget** - Android/iOS виджеты
- **json_annotation** - JSON сериализация
- **uuid** - Генерация уникальных ID

### Хранение данных:

Все расписание хранится **локально** на устройстве в SharedPreferences в формате JSON. Данные **не синхронизируются** с облаком.

### Минимальные требования:

- **Android:** 5.0 (API 21) и выше
- **iOS:** 12.0 и выше (виджет работает ограниченно)

## 📝 Примеры использования

### Типичный сценарий:

1. **Первый запуск:** Добавьте расписание на всю неделю
2. **Каждое утро:** Посмотрите уведомление с сегодняшними уроками
3. **В течение дня:** Быстро проверьте виджет на домашнем экране
4. **Изменения:** Отредактируйте урок если время или кабинет изменились

### Советы:

- Используйте **одинаковые цвета** для одинаковых предметов
- Добавьте **номера кабинетов** чтобы не забыть куда идти
- Создайте **постоянное уведомление** если часто смотрите расписание
- Добавьте **виджет на экран блокировки** Android (если поддерживается)

## 🌟 Особенности

### Шестидневка:

Приложение поддерживает **7 дней недели**, включая субботу и воскресенье. Можете добавлять уроки на любой день.

### Гибкое время:

- Нет ограничений на время уроков
- Можете создавать уроки в любое время дня
- Уроки **автоматически сортируются** по времени начала

### Автодополнение:

При вводе предмета появляются **популярные названия** (Математика, Русский язык, и т.д.). Можно вводить и свои.
